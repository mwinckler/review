## Highlights

- Pick up where you left off with `review last`, or use `review` to compare your work with the nearest named parent. Press `B` to change the comparison without leaving the review.
- Navigate the diff with a visible row cursor and comment directly on selected lines. Viewed files, comments, and your position are saved with the session.
- Review GitLab merge requests, read and reply to discussions, and submit your feedback from the terminal.

## Install and update

Install this release with Cargo:

```sh
cargo install --locked --git https://github.com/mwinckler/review.git --tag v0.10.0 review
```

For future releases, run `review update --check` to check for updates, `review update --notes` to see what changed, and `review update` to install the new version.
